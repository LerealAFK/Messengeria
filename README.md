# **Messengeria - Réseau Social Dynamique**

**Messengeria** est un réseau social dynamique, simple et élégant, conçu pour offrir une expérience utilisateur moderne et engageante. Ce projet comprend des fonctionnalités telles que la messagerie privée, les conversations en temps réel, les profils utilisateurs personnalisés, et bien plus encore.

## **Technologies utilisées**

Le projet **Messengeria** a été développé en utilisant plusieurs technologies modernes qui garantissent une expérience fluide et interactive. Voici les principales technologies utilisées :

- **Frontend :**
  - **HTML5** : Structure de base du site.
  - **CSS3** : Mise en forme et design, avec des fonctionnalités modernes telles que le mode sombre.
  - **JavaScript** : Pour la dynamique du site, notamment pour les interactions utilisateurs comme les messages privés et les notifications.
  - **PHP** : Côté serveur pour gérer les utilisateurs, les messages et les autres fonctionnalités dynamiques.
  - **MySQL** : Base de données relationnelle pour stocker les utilisateurs, messages et conversations.

- **Backend :**
  - **PHP** : Langage utilisé pour la gestion des requêtes, des sessions utilisateurs et des actions sur la base de données.
  - **PDO** : Accès sécurisé à la base de données pour éviter les injections SQL.
  - **AJAX** : Pour charger les messages en temps réel sans recharger la page.

## **Fonctionnalités principales**

**Messengeria** offre plusieurs fonctionnalités intéressantes pour améliorer l'expérience utilisateur :

### 1. **Profils Utilisateurs**
   - Chaque utilisateur a un profil personnalisé avec la possibilité de modifier ses informations, y compris son email et mot de passe.
   - Affichage des messages privés associés à chaque profil.

### 2. **Messagerie Privée**
   - Les utilisateurs peuvent commencer de nouvelles conversations avec d'autres utilisateurs via un moteur de recherche.
   - Système de messagerie privée sécurisé, permettant l'échange de messages en temps réel.

### 3. **Notifications de Conversations**
   - Un système de notification qui indique les nouvelles conversations ou messages.

### 4. **Conversations en Temps Réel**
   - Possibilité d'envoyer et recevoir des messages instantanément sans avoir besoin de recharger la page.

### 5. **Mode Sombre**
   - La plateforme permet aux utilisateurs de basculer entre le mode sombre et clair pour améliorer l'accessibilité.

### 6. **Fonctionnalités de Sécurité**
   - Les mots de passe sont hachés et sécurisés.
   - Utilisation de sessions pour garantir la sécurité des utilisateurs.
   - Validation des utilisateurs avant l'accès aux fonctionnalités importantes.
